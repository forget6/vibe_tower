# 扫描清单模板（Scan Playbook）

> 用途：把"判据"从**归因字典**变成**探照灯** —— 每条判据 MUST 附带**可执行的扫描动作**，
> 使缺陷发现从"遇到才发现"变成"**按清单扫出来**"。
> 本文件是**通用骨架**：项目侧 MUST 据其生成本项目清单实例（补齐该项目特有的路径、命令与证据），
> 并保留"判据 → 扫描动作"的**机制口径**不变。

## 1. 机制

每条判据在清单里 MUST 落成**四元组**：

| 字段 | 含义 | 硬性约束 |
|---|---|---|---|
| 判据 | 来自本塔的条目/机制名（含 ★版本） | MUST 可追溯到塔的具体小节 |
| 扫什么 | 该判据在**代码/产物/配置**里的可观测特征与位置 | MUST 具体到"特征 + 位置"，MUST NOT 是"检查有无问题" |
| 命中即缺陷的样子 | 满足什么形态即判为违反 | MUST 可判定（是/否），MUST NOT 用程度副词 |
| 怎么扫 | 可复制执行的扫描动作（命令 / 查询 / 断言名） | MUST 能直接执行；等价工具须注明替换关系 |

## 2. MUST

- A 每条判据 MUST 落成上述**四元组**；清单 MUST **全量覆盖**该项目已登记的判据条目。
- B 清单 MUST 在**使用现场**执行：**设计评审预扫**（逐条给"命中 / 不适用"）→ **缺陷定位先扫后改** → **交付校验在闸门内完成**。
- C 命中项 MUST 记为缺陷，或走**显式豁免**（含理由与责任人）。
- D 判据集升版（新增/改名/合并）⇒ 清单 MUST **同步**，且该同步 MUST 由**机械卡口**校验覆盖度。
- E 扫描动作 MUST 有**跨工具的等价表达**（同一判据在不同技术栈/工具链下可落地）。
- F **扫描面与阈值 MUST 有据**：带阈值的扫描动作 MUST 先跑一次取**实测基线**（登记**数值 + 取基线时的版本/日期**），再以基线设**下限** → MUST NOT 用直觉或"凑整"设阈值；扫描面 MUST **同时断言「已知源全部被扫到」**（逐条列出必须命中的源），MUST NOT 只断言"扫到 N 条"（漏扫时总数可能仍然达标 ⇒ 卡口形同虚设）；阈值/基线变更 MUST 就地留痕（旧值 → 新值）。

## 3. NEVER

- A 只写判据不写扫描动作（不可执行的清单等于没有清单）。
- B **事后补档**：先改完再补校验 —— 正向校验 MUST 在闸门内完成。
- C 清单与判据集**不同步**（清单腐化 ⇒ 判据退回"归因字典"）。
- D 只写"已扫描"而无逐条结论与证据（无结论 = 未校验）。
- E 把扫描动作绑死到某一种语言/工具而无等价说明（清单即不可移植）。
- G 只断言"扫到 N 条"而**不断言「已知源全部被扫到」**：漏扫与新增遗漏在总数上不可区分 ⇒ 覆盖度无人守。
- F 阈值**无来源**：下限取自直觉/凑整，无实测基线、无取基线时的版本 —— 后果有二：**判据自杀**（把本来合规的现状判红，进而被人关掉）或**判据空转**（阈值过低，漏扫也不红）。

## 4. 通用判据 → 扫描动作（骨架表）

| 判据 | 扫什么（特征/位置） | 命中即缺陷的样子 | 怎么扫（可执行形态） |
|---|---|---|---|---|
| 必命中 | 新规则/新分支是否声明"输入 X ⇒ 必须命中" | 只有实现、没有"该命中"的断言（规则空转） | 运行该规则的用例集，核对其含"命中"用例且通过 |
| 必不误报 | 是否有"输入 Y ⇒ 不得命中"的断言（真实反例：同名标识符 / 语法变体 / 边界形态） | 只测正例 ⇒ 误报面无人守 | 运行合规语料与回归集，核对零命中 |
| 静默失效 | 未识别输入是否静默跳过（无日志 / 无计数 / 无告警） | 默认分支、空返回、跳过分支无任何信号 | 检索默认分支与空返回，逐处核对有无信号 |
| 口径唯一 | 同一事实是否在多处各算一遍（计数 / 长度 / 截取 / 包含） | 两处各自实现同一口径（改一处漏一处） | 以"量名"为关键词全仓检索，≥2 处实现即命中 |
| 锚点唯一 | 解析 / 定位所用锚点是否唯一（配对标记 / 前缀 / 编号） | 锚点可被扩展形态歧义命中（拿不准却报） | 检索定位式解析（切分 / 索引），核对锚点唯一性 |
| 枚举兜底 | 枚举 / 白名单 / 开关缺项是否有信号 | 未识别值走默认分支被静默放行 | 检索分支语句，逐 case 核对兜底 |
| 结果语义三值化 | "未命中 / 失败"是否被压成两值 | 以"错误对象为空"反推存在；解析不到就猜一个值 | 检索空值判定与错误判定，核对三值区分 |
| 读回核验 | 跨系统写操作后的成功判据来源 | 只看调用返回 / 退出码就判成功 | 检索写路径的返回值判定，核对是否有"执行后读回" |
| 环境事实运行时查询 | 硬编码的环境事实常量与文档 / 文案固化 | 常量写死某个主体；或用文案固化假设 | 检索环境常量与界面 / 文档文案，核对是否执行时查询 |
| 存量迁移纪律 | 写路径是否自动改写存量、查重键是否与命名无关 | 按"新名"查重；批量路径顺带改写存量 | 检索写调用与查重条件，核对查重键 |
| 生成规则单真源 | 命名 / 编号 / 路径 / URL 的生成规则有几处实现 | 展示侧与落库侧各写一份（预览与实际分叉） | 以规则特征串全仓检索，≥2 处实现即命中 |
| 断言演进纪律 | 字面量断言、负向断言（无补证）、定位式断言（界定失败） | 等值断言钉住会增长的量；负向断言空转；界定失败退化成全扫 | 检索断言文件中的字面量与定位逻辑，核对补证方式与硬失败 |
| 越权 / 角色收口 | 入口的**动作级**权限；读写是否被同一门槛连带 | 读操作被绑上写门槛；或为修可用性连带放开写操作 | 检索权限分组与角色判定，逐个入口核对动作级 |
| 凭据不外泄 | 日志 / 通知 / 集合响应里的敏感原文 | 明文凭据进日志或对外正文 | 检索敏感字段名与输出路径，核对脱敏 |
| 发布产物核验标记 | 产物内嵌标记的**类型**与**负例** | 用标识符当标记（符号剥离 ⇒ 假不命中）；无负例 | 核对产物内标记的正例与负例 |
| 降级/回落成套 | 所有回落 / 兜底分支是否**成套**且有信号 | 只回落一半 ⇒ 半旧半新混合形态；静默回落 | 检索兜底分支，逐分支核对配套要素与信号 |
| 权限收口按动作 | 门槛是否由**动作**定级（读 / 写 / 删 / 授权分离） | 模块级门槛连带；"合法角色被拦"未记缺陷 | 复用"越权 / 角色收口"动作 + 核对**放宽范围** |
| 输出必要要素集 | 面向人的输出正文要素 | 只给标识符，接收者需二次查询；要素取自未脱敏源 | 检索输出构造处，核对「主体 / 目标 / 动作 / 结果」齐备 |
| 派生视图来源与时效 | 台账 / 缓存 / 汇总类展示是否标注来源与新鲜度、是否给出实时真源入口 | 派生数据被当作事实来源；生效结论取自派生物 | 检索展示层的派生字段，核对标注与真源入口 |
| 同族完备 | 同一错误假设 / 硬编码事实的**全部**使用点 | 只修被报告的一处，其余同族点继续按旧假设运行 | 以被修假设的特征串全仓检索，逐个使用点核对 |
| 共同加工单施加点 | 对**全分支**成立的加工（装饰 / 归一化 / 脱敏 / 权限标注 / 类型标签）写在哪 | 加工写在某条分支内 ⇒ 其余分支该字段静默为空，下游兜底显示"未知/空"，而列表 / 台账侧正确 | 检索加工调用（装饰 / 脱敏 / 归一化），核对**恰好一处且先于分派** |
| 长内容规模自适应 | 输出里直接绑定的**可增长内容**（条目 / 语句 / 日志 / 明细） | 数十 KB 文本或上千条明细一次性渲染进界面（不可读、不可检视） | 检索输出绑定处与分页/折叠/下载入口，核对是否存在规模分支 |
| 截断来源标注 | 内容取自**有存储上限**的载体（截断日志 / 采样 / 摘要 / 缓存）时是否标注 | 截断样本被当作全文展示，且无完整内容入口 | 检索载体上限常量与展示落点，核对截断标记与完整内容入口 |
| 理解有据（功能模型） | 本轮受影响功能的**功能模型**是否存在，且每条有**可定位证据锚** | 凭关键词命中就改；功能条目无证据锚（把"未查清"当"已理解"） | 读项目侧功能地图，逐条核对证据锚是否真实存在；缺失者回到未知项清单 |
| 业务细节零入塔 | 通用文档/模板里是否出现业务名 / 库表名 / 字段 / 流程细节 | 塔被污染 ⇒ 无法开源、无法即插即用 | 以禁用词表扫描塔侧全部交付物；命中即以"通用表达"重写 |
| 仿制差异有据 | 复用类改动是否有**四分类差异清单**（保留/改写/新增/删除，逐项"参照锚→目标锚→理由"） | 只写"参照某功能即可"；某类空缺且未写"无"；参照锚不存在（模板选错/臆造） | 读项目侧差异清单，逐项核对四类齐备、锚点真实存在 |
| 呈现按功能 | 复用类改动是否沿用参照功能的**呈现面**（字段/措辞/危险提示/权限门/脱敏/长内容规模策略） | 呈现被照抄 ⇒ 语义错位（"看着对、含义错"）；不同项无断言 ⇒ 无人拦 | 比对参照与新功能的呈现绑定处，逐项核对"判定依据 + 不同项断言" |
| 常驻约束有载体 | 横切要求（环境隔离/日志/凭据/命名/审计/权限）是否已进**常驻约束清单**：适用范围 + **机器判据** + 生效载体 + 存量基线 | 约束只存在于"人记得"/每轮口头提醒；判据不可机械判定；存量违规无基线（一次大改或放任） | 读项目侧常驻约束清单，逐条核对四要素齐备且判据可执行；缺失者补载体 |
| 施工期已生效 | 约束是否在**写代码时**已生效（载体：约定文件/编辑器规则/会话基线/闸门），还是只在交付时检查 | 交付前才补 ⇒ 施工期已产生偏差（且往往只修表面） | 核对载体清单与实际改动时序；发现"事后补"即归因到载体缺口 |
| 横切维度成熟度与下一级台阶 | 横切约束是否登记了**当前级别（L0–L3）**与**下一级台阶** | 只写"禁止/要求"而无合规做法与升级动作 ⇒ 判据**路障化**（执行者只能试错或绕过）；级别靠自我感觉、无客观特征；基线永存（只登记不收敛） | 读项目侧常驻约束清单，逐条核对「成熟度级别 ∈ L0–L3」+「下一级台阶为可执行动作」+「级别与存量基线自洽（有存量 ⇒ 至多 L2）」；再核对 `README` §1.1 阶梯特征 |
| 扫描面与阈值有据 | 带阈值的扫描动作：下限取值与其来源；扫描面覆盖清单 | 阈值靠猜/凑整（无实测基线）；只断言总数、不断言"已知源全部在场" | 先跑一次记录实测基线（数值 + 版本/日期）→ 以基线设下限；逐条列出"必须被扫到"的源并断言其在场；基线变更就地留痕 |
| 范围维度全集态（写作用域） | 范围维度（环境/租户/项目/归属）的筛选控件与取数传参 | 「全部 / 不限」态**可达**或为**默认**；取数用"有值才传参"的条件式（空 ⇒ 不过滤 ⇒ 静默全集） | 检索筛选控件的"全部 / 不限"选项与其绑定动作、取数处的条件式传参；核对默认值是否为**最窄**作用域；核对异域入参是**收敛**还是落全集 |
| 会合法变化之物 vs 断言锚定 | 断言锚定的对象：①"会前进的当前值"（指纹 / 版本串 / 计数）落在**当前真源**还是**历史记录** ②断言里是否出现**实现的具体写法**（整行代码 / 精确表达式串） | ① 历史记录被要求等于当前值（每次前进即自红）；历史值被"回改"成当前值 ② 断言钉住某次修复的具体写法 ⇒ **合法重构即自红**（红的是断言，不是代码） | 读断言：核对当前值只钉当前真源、历史记录只断言"仍登记着**当版**值"；检索断言中的**精确实现串**，核对可否改为**形态**断言（"旧坏形态 MUST NOT 出现" / "该扫描零命中" / "该量 MUST NOT 回退"） |
| 缺陷归因可复核 | 缺陷报告的**首个响应**：取证产物、归因顺序、假设的形态 | 先归因**报告者 / 环境**且**无取证动作**；用**结论式**归因代替（"你没刷新吧"——既无步骤也无证据）；环境假设未附**核对步骤 + 证据对照**；把"报告者说了"当作**免于验证**的理由 | 读缺陷处理记录首步：是否有**取证产物**（复现输出 / 源码行证据 / 卡口输出 / 产物指纹）；核对任何归因是否附「**核对步骤 + 期望证据 vs 实际证据**」；分歧是否转成**可判定实验** |

## 5. 落项目时的填写规则

| 项 | 规则 |
|---|---|
| 证据列 | 每行 MUST 补「本项目证据」（用例名 / 文件位置），并与该项目的**判据 ↔ 证据映射表**一致 |
| 覆盖校验 | 由项目侧**机械卡口**保证：清单 MUST 覆盖映射表的**全部**条目；新增判据而未补清单 ⇒ **阻断** |
| 版本联动 | 判据集升版 ⇒ 清单 MUST 同步（不同步 ⇒ 视为**缺陷**，而不是"待办"） |
| 时机落点 | 预扫（设计评审）→ 先扫后改（定位）→ 闸门内（交付校验）三处 MUST 写进项目流程文件 |
| 基线列 | 每条带阈值的扫描动作 MUST 登记**实测基线**（数值 + 取基线时的版本/日期）与**必须命中的源清单**；基线/阈值变更 MUST 就地留痕（旧值 → 新值） |

## 6. 反模式

| 反模式 | 现象 | 纠正 | 扫描动作 / 证据 |
|---|---|---|---|
| 不可执行清单 | 只写"检查是否存在问题" | 补可复制的扫描动作 |
| 事后补档 | 改完才做校验 | 校验进闸门内，禁止事后补 |
| 清单腐化 | 判据新增 / 改名，清单不动 | 机械卡口校验覆盖度 |
| 自查即通过 | 只有"已扫描"没有结论 | 逐条给"命中 / 不适用" + 证据 |
| 归因字典 | 判据只在**事后归因**时被引用，从不用于**主动扫描** | 按 §2B 在三个现场执行清单 |
| 阈值靠猜 | 下限是直觉/凑整数字，无实测基线（首跑即把合规现状判红） | 先取实测基线再设下限；断言"已知源全部被扫到"；变更留痕 |
| 相邻判定的差异显式 | 语义相邻的集合 / 谓词：成员表与判定依据 | 集合成员不同却无断言；谓词互相替代；为"看起来像"而合并两集合 | 逐格比对各集合成员并检索其差异断言；检索同一状态空间上的多个谓词是否各自登记依据 |
| 判据双层覆盖 | 每条判据的两类证据：行为断言（真值表 / 用例）与结构断言（源码级检索） | 只有行为断言 ⇒ 拦不住"别处又写一套"；只有结构断言 ⇒ 拦不住"判定本身写错"；结构层**命中面按关键词出现**定义 ⇒ 误伤合法写法（卡口被人关掉） | 读判据文件：核对是否**同时**含真值表 / 用例与源码级检索两类断言；结构层命中面 MUST 以**缺陷形态**定义（如"缺省回退"），MUST NOT 以"关键词出现"定义 |
| 收敛前先枚举 | 词表 / 集合收敛前的取值清单与定性记录 | 未枚举即批量替换（漏一个即误判） | 读收敛前的定性记录：是否列出全部取值（含大小写 / 别名域）及其所属域 |
| 格式面只减基线 | 静态检查 / 格式面的存量违规与改动边界 | 无基线；格式修复与功能修复混在同一次改动 | 读格式面基线登记（数值 + 清单 + 日期）；核对功能改动是否夹带重排 |

# 类比复用差异清单模板（Clone-Diff Template）

> 用途：当"**照着已有功能做一个新功能**"或"**复用已有功能做微调**"时，把"哪些复用、哪些必须按新功能改写"
> 落成**可评审、可卡口、可追溯**的清单（见 `extensions/07-analogical-reuse.md`）。
> **本模板不含业务信息**，可随知识塔一起开源；填写后的实例**属于项目**（含业务事实），MUST NOT 回写进塔。
> 填写规则：`MUST` = 不留空（无该项写"无"）；`NEVER` = 禁止的填法（尤其：**NEVER 照抄呈现面**）。

## 0. 头部（MUST 填）

| 字段 | 填写规则 |
|---|---|
| 新功能（目标） | `MUST` 一句话说明新功能要实现什么 |
| **参照功能**（模板） | `MUST` 指明用来参照的既有功能 |
| **相似度依据** | `MUST` 逐条写：同状态机 / 同入口 / 同数据通路 / 同失败语义（不足 ⇒ MUST NOT 当模板） |
| 最后更新时点 / 版本 | `MUST` 标注（活工件） |
| 未决项 | `MUST` 与第 4 节条数一致 |

## 1. 骨架复用点（`MUST` 单一真源）

| # | 复用面（流程顺序 / 状态机 / 守卫 / 失败语义 / 审计与通知骨架 / 接口形状） | 以哪里为**单一真源**（证据锚） | 新功能如何引用（`NEVER` 复制第二份实现） |
|---|---|---|---|
| 1 | | | |

## 2. 四分类差异清单（`MUST` 四类齐全，逐项有锚与理由）

| # | 类别 | 项（字段 / 接口 / 守卫 / 呈现 …） | 参照位置（证据锚） | 目标位置 | 理由（为何同 / 为何改） |
|---|---|---|---|---|---|
| 1 | **保留（同）** | | | | |
| 2 | **改写（按新功能）** | | | | |
| 3 | **新增** | | | | |
| 4 | **删除** | | | | |

> `NEVER` 只写"参照某功能即可"——差异 MUST 逐项判定（漏改/漏删正是这样发生的）。

## 3. 呈现面判定表（`MUST` 按**新功能**逐项判定；MUST NOT 沿用参照）

> 判定纪律：**流程可同构，呈现按功能** —— 呈现面每一行 MUST 写出**新功能**应有的结果与其判定依据；
> 直接沿用参照功能的字段 / 措辞 / 危险提示 / 权限门 / 脱敏 / 规模策略 ⇒ 语义错位（"看着对、含义错"）。

| 呈现面 | 参照功能的做法（证据锚） | 新功能应当是什么 | 判定依据（新功能的功能模型） | 双向断言 |
|---|---|---|---|---|
| 展示字段集 | | | | 相同项：防漂移 / 不同项：防照抄 |
| 措辞与危险提示 | | | | |
| 权限门（谁可看 / 谁可改） | | | | |
| 脱敏策略（凭据 / 密文 / 原文） | | | | |
| 长内容呈现（摘要 / 分页 / 下载 / 截断标注） | | | | |

## 4. 未知项清单（`MUST` 显式）

| # | 未知点 | 影响 | 澄清动作 | 状态 |
|---|---|---|---|---|
| 1 | | | 提问 / 探查（相似度不足？呈现口径未定？边界不清？） | |

## 5. 双向卡口（`MUST` 两侧都写）

| 类 | 断言/关卡（路径#用例名） | 防的是 |
|---|---|---|
| **相同项**（骨架复用） | | 骨架漂移（两份实现/两处口径） |
| **不同项**（呈现分离） | | 照抄错位（把参照的呈现搬到新功能） |

> 交付前自检：**双向卡口**的价值 = **相同项防漂移** + **不同项防照抄**（缺其一即失守）：
> **没有"不同项"的断言** = 照抄无人拦；**没有"相同项"的断言** = 骨架可被各自改写。
